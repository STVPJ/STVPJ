# Hi, I'm Steve James

**Product leader · AI products · Builder**

I'm a product manager on a legal-AI product. I build my own tools with Claude Code, and I care about the parts of AI products that demos skip: evals, consistency, cost and failure modes. The repos here are cleaned-up versions of pipelines I run every day, with any work-specific context removed. I write about what I learn at [stvpj.com](https://stvpj.com).

---

### AI pipelines for product work

**[competitive-briefing](https://github.com/STVPJ/competitive-briefing)**: a daily competitive-intelligence briefing. Code gathers, de-duplicates and checks freshness, then one structured Claude call writes the briefing. It replaces about 30 minutes of feed-reading with a 5-minute read.

**[reddit-sentiment](https://github.com/STVPJ/reddit-sentiment)**: daily product sentiment from Reddit. It makes one typed judgment per comment instead of asking an LLM for a vibe score, and a drill-down dashboard links every number to the comments behind it.

### Tools for product managers

**[story-mapper](https://github.com/STVPJ/story-mapper)**: a local-first story-mapping tool with Feature → Epic → Story hierarchy, release slicing and Jira / Azure DevOps export. No account and no server.
